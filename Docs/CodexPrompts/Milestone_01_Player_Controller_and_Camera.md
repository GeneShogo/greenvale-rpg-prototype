# Milestone 01 Prompt Summary - Player Controller and Camera

Project: Greenvale RPG Prototype  
Engine: Unity URP  
Milestone: Milestone 1 - Player Controller and Camera

Implement a license-safe, original third-person player controller and camera follow system for the GreenvaleAbbey scene. Keep changes focused on this milestone and place project-created scripts and documentation under `Assets/_Project/` and `Docs/`.

Acceptance goals:

- WASD movement.
- Sprint.
- Jump.
- Camera follow and mouse rotation.
- Configurable movement speed, sprint speed, jump force, gravity, camera sensitivity, and interaction distance.
- Use the existing `PlayerSpawnPoint` where practical.
- Add an interaction raycast that detects objects implementing `IInteractable`.
- Avoid World of Warcraft or other copyrighted assets, names, quest text, icons, maps, or music.
- Update `Docs/CHANGELOG.md`, `Docs/BuildNotes.md`, and add `Docs/Systems/PlayerController.md`.
